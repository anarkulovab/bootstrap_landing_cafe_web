# Bootstrap Coffee Landing

Адаптивный лендинг кофейни на Bootstrap 5. Карточки товаров, баннер с акцией, dropdown-навигация.

## Демо

[Открыть сайт](https://ТВОЙ_ЛОГИН.github.io/bootstrap-coffee-landing/) — если включишь GitHub Pages.

## Скриншот

(screenshots/page_screenshot.png)

## Стек

- HTML5
- CSS3
- Bootstrap 5.3
- JavaScript (базовый)

## Что реализовано

- Адаптивная сетка Bootstrap (`row-cols-1 row-cols-md-2 row-cols-lg-4`)
- Навигация с dropdown-меню
- Баннер с наложением текста на изображение (`card-img-overlay`)
- Карточки товаров с ценой и кнопкой «В корзину»
- Футер
